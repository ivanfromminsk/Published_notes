# Obsidian для командной работы

## Требования

- Организовать командную работу над архитектурными проектами в Obsidian. Оценить скорость и надёжность синхронизации через Dropbox и GitHub при большом количестве файлов и изображений, в том числе имеет ли смысл докупать место на GitHub.
- Редактировать одну заметку одновременно, как в Google Docs, и оставлять комментарии. Проверить, что можно сделать бесплатными плагинами и работает ли совместное редактирование в Canvas и Excalidraw.
- Использовать Canvas как общую доску наподобие Miro. Коллеги должны видеть планы и рендеры прямо на доске. Проверить, можно ли хранить картинки в общей папке Dropbox и показывать их внутри Canvas.
- Вставлять таблицы прямо в текст, как в Word, и считать по формулам в ячейках, как в Excel.
- Сохранять заметки как редактируемые документы Word и PDF. Экспортировать Canvas в PDF с сохранением расположения карточек и связей.
- Открывать общие рабочие заметки как папку в текущем хранилище Obsidian, сохранив синхронизацию личных заметок через GitHub.
- При необходимости давать ChatGPT доступ к материалам проекта в Dropbox.

## Где что хранить

- **Obsidian** — бриф, протоколы, журнал решений, сравнение вариантов и рабочие доски Canvas. На доске обсуждаем планы и оставляем замечания, а принятые решения записываем в связанной заметке.
- **Dropbox** — модели, DWG, PSD, полноразмерные рендеры и прочие исходники. Из Obsidian даём ссылки Dropbox с доступом для команды.
- **Excel или Google Sheets** — ТЭП, баланс территории и ведомости площадей. В Obsidian ведём небольшие таблицы для сравнения вариантов, при необходимости с простыми формулами.

## Совместная работа и картинки

- Если команда правит заметки и доски **по очереди**, можно открыть общую папку Dropbox как хранилище Obsidian. На всех компьютерах папку нужно сделать доступной офлайн. При одновременном изменении одного файла Dropbox может создать конфликтную копию.
- Если нужно **одновременно редактировать одну заметку или Canvas**, у каждого участника свой локальный Obsidian, а общую папку заметок и досок синхронизирует **Relay**. Совместные правки появляются в реальном времени. Одни и те же файлы нельзя синхронизировать одновременно через Relay и Dropbox.
- **Relay Free** — до трёх участников, живое редактирование Markdown и Canvas. Для автоматической передачи локально вставленных изображений и PDF через облако Relay нужен платный тариф. Полноразмерные файлы можно оставить в Dropbox, а для досок использовать лёгкие JPG-превью.
- Если картинки остаются только в Dropbox, обычная ссылка открывает файл по клику. Для показа прямо в текстовой карточке Canvas можно попробовать Markdown-вставку с прямой ссылкой Dropbox (`raw=1`). Ссылку с текущими правами доступа нужно проверить на компьютере коллеги. Если просмотр требует входа, встроенная картинка может не загрузиться.
- GitHub удобен для истории Markdown и шаблонов. Синхронизация через Git идёт по циклу commit, push и pull, а тяжёлые вложения увеличивают объём репозитория. Для этой схемы достаточно Dropbox для исходников и Relay для живой работы.

## Одно хранилище для личных и командных заметок

- Оставить текущее хранилище Obsidian. Для командных заметок и досок подключить общую папку Relay, например `Work/Zrobim/Team/`. Она появится в обычном дереве файлов рядом с личными заметками. Коллеги подключают эту же папку в своих хранилищах через Relay.
- Личные заметки и рабочие черновики продолжают синхронизироваться через Obsidian Git и GitHub. Перед подключением командной папки добавить `/Work/Zrobim/Team/` в корневой `.gitignore`, чтобы Git не подхватил её файлы.
- Если в командную папку попадут файлы, уже отслеживаемые Git по этому пути, их надо отдельно убрать из отслеживания с сохранением локальных файлов. Уже записанные в Git версии останутся в истории.
- Модели, полноразмерные рендеры и прочие исходники остаются в Dropbox. Командные заметки и Canvas синхронизируются через Relay, а из Obsidian можно открывать исходники по ссылкам.

## Плагины и встроенные функции

| Компонент | Что использовать |
| --- | --- |
| Доска с карточками, связями и вложениями | **Canvas**, встроенный плагин Obsidian. Штатный экспорт доски на компьютере — PNG. |
| Живое редактирование текста и досок | [Relay](https://community.obsidian.md/plugins/system3-relay). Всем участникам общей папки нужно установить плагин. |
| Комментарии, ревью и согласование | **Relay Comments**, бесплатный отдельный плагин. Комментарии к тексту, обсуждения, предложения правок с принятием или отклонением, пины на Canvas. |
| Таблицы в тексте | Встроенные Markdown-таблицы. Для формул в ячейках, например суммы или умножения, — [Table Calc](https://community.obsidian.md/plugins/table-calc). Если нужны фильтры и расширенные функции, попробовать [Power Tables](https://community.obsidian.md/plugins/powertables) вместо Table Calc. |
| Заметка в PDF | Встроенная команда **Export to PDF**. Поддерживает A3, A4, альбомную ориентацию, поля и масштаб. |
| Заметка в редактируемый Word | [Enhancing Export](https://community.obsidian.md/plugins/obsidian-enhancing-export) и отдельно установленный [Pandoc](https://pandoc.org/). Для фирменных стилей можно использовать эталонный DOCX. |
| Canvas в PDF | [CanvasPort](https://community.obsidian.md/plugins/canvasport). Экспортирует доску на компьютере с расположением карточек и связей. |
| Расширенное оформление досок | **Advanced Canvas** по необходимости. Добавляет фигуры, сворачиваемые группы и режим презентации. Совместимость с Relay проверить на тестовой доске. |
| Совместный рисунок от руки | Для разовой сессии — [Excalidraw в браузере](https://excalidraw.com/). Для работы внутри Obsidian — Excalidraw и [Excalidraw Live Sync](https://community.obsidian.md/plugins/excalidraw-live-sync), который требует общей локальной или виртуальной сети. |
| Совместное редактирование заметки из браузера | [Peerdraft](https://www.peerdraft.app/) по необходимости, как отдельный вариант для текстовых заметок, когда у участника нет Obsidian. |

## Пилот на одном проекте

1. Взять один протокол и одну доску с вариантами генплана. Начать с Canvas, Relay и Relay Comments.
2. На двух компьютерах одновременно изменить один абзац и одну карточку. Поставить пин у въезда и ответить на комментарий.
3. Добавить один рендер с текущими правами Dropbox. Проверить, отображается ли он у обоих прямо на доске. Отдельно замерить, как быстро в Dropbox появляются обычная заметка, пачка превью и большой файл.
4. Выгрузить доску в PDF и проверить читаемость на A3. При проверке Word и PDF открыть экспорт с картинкой и таблицей и убедиться, что в нём видны рассчитанные значения.

**Доступ из ChatGPT.** После подключения приложения Dropbox можно выбрать доступную папку проекта или отдельные файлы. Для разбора общей доски удобно приложить её экспорт в PDF вместе с нужными изображениями.
