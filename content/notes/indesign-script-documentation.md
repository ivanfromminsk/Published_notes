# Инструкция пользователя

## Markdown Synchronization for Adobe InDesign

### 1. Назначение

Скрипт синхронизирует текстовые фреймы Adobe InDesign с содержимым внешнего Markdown-файла.

Текст редактируется в Markdown, после чего скрипт показывает предварительный просмотр изменений и позволяет обновить содержимое InDesign.

Скрипт не предназначен для создания макета. Он не должен менять размеры и положение существующих текстовых фреймов или создавать новые.

### 2. Подготовка документа

Перед синхронизацией каждому текстовому фрейму необходимо назначить идентификатор.

1. Выберите текстовый фрейм.
    
2. Откройте **Window → Utilities → Script Label**.
    
3. Введите идентификатор, например `ANALISYS_01`.
    
4. Повторите для остальных фреймов, которые должны синхронизироваться.
    

Идентификатор должен содержать только латинские буквы, цифры и символы подчёркивания. Регистр имеет значение.

**Важно:** в текущей версии скрипта повторяющиеся идентификаторы обнаруживаются и выводятся как ошибка. До исправления этой особенности используйте уникальный идентификатор для каждого фрейма.

### 3. Подготовка Markdown-файла

Создайте файл с расширением `.md`. Его можно редактировать в любом текстовом редакторе, поддерживающем Markdown.

Каждый раздел начинается с заголовка первого уровня, содержащего идентификатор текстового фрейма.

Пример:

```
# ANALISYS_01 {style=Body Copy}

Первый абзац.

Второй абзац с **полужирным** и *курсивом*.

{style=Caption}Подпись к изображению.

Текст с {char=Accent}акцентным фрагментом{/char}.

# CONCEPT_01

Текст второго раздела.
```

Заголовки с идентификаторами являются служебными и не попадают в текст фрейма. Содержимое каждого раздела относится к соответствующему идентификатору до следующего заголовка.

#### Поддерживаемое форматирование

**Абзацы.** Пустая строка разделяет абзацы. Несколько пустых строк подряд считаются одним разделителем. Перенос строки внутри абзаца объединяется пробелом.

**Стиль абзаца для всего раздела.** Запись `{style=Body Copy}` после идентификатора в заголовке задаёт стиль по умолчанию для раздела.

**Стиль отдельного абзаца.** Запись `{style=Caption}` в начале абзаца задаёт стиль только для него. Директива не отображается в итоговом тексте.

Если указанный стиль абзаца отсутствует, скрипт выводит предупреждение и пытается использовать стиль раздела или существующее оформление фрейма.

**Полужирный и курсив.** Используйте стандартный Markdown:

- `**полужирный текст**`
    
- `*курсивный текст*`
    

В документе InDesign заранее должны существовать стили символов `Markdown Bold` и `Markdown Italic`.

**Произвольный стиль символов.** Используйте конструкцию:

`{char=Accent}текст{/char}`

Вместо `Accent` укажите точное название существующего стиля символов InDesign. Сам стиль скрипт не создаёт.

**Маркированный список.** Строки, начинающиеся с `-` , обрабатываются как пункты списка. Для них используется существующий стиль абзаца `Bullet`.

### 4. Запуск скрипта

1. Откройте нужный документ InDesign.
    
2. Откройте панель **Window → Utilities → Scripts**.
    
3. Запустите скрипт `Markdown_InDesign_Sync.jsx`.
    
4. Выберите одну из команд.
    

**Link Markdown file / choose another** — выбрать Markdown-файл или изменить ранее выбранный файл.

**Update previously linked file** — повторно прочитать ранее выбранный файл без нового выбора. Если файл перемещён, удалён или недоступен, скрипт сообщит об этом.

**Toggle Script Label markers** — создать или удалить визуальные метки идентификаторов рядом с фреймами. Метки находятся на отдельном непечатаемом слое.

Путь к последнему выбранному Markdown-файлу сохраняется в метках документа InDesign.

### 5. Предварительный просмотр и применение изменений

Перед обновлением скрипт показывает окно предварительного просмотра.

В нём отображаются:

- идентификатор фрейма;
    
- статус изменения;
    
- количество абзацев;
    
- стиль по умолчанию;
    
- страница или страницы;
    
- предупреждения и ошибки;
    
- старое и новое содержимое выбранного раздела.
    

Основные статусы:

- **WILL UPDATE** — текст отличается и будет обновлён.
    
- **UNCHANGED** — текст не требует обновления.
    
- **NOT FOUND** — в документе не найден фрейм с таким идентификатором.
    

Выберите строку отчёта, чтобы просмотреть старый и новый текст.

**Cancel** отменяет операцию до применения изменений.

**Apply updates** применяет обновления для доступных изменённых разделов. Перед нажатием проверьте текст и предупреждения. Не применяйте изменения, если отчёт показывает неожиданные результаты.

После синхронизации скрипт сообщает о количестве обновлённых разделов и фреймов, а также предупреждает о переполнении текстовых фреймов.

### 6. Проверка результата

После применения изменений рекомендуется:

1. Проверить текст и форматирование обновлённых фреймов.
    
2. Проверить переносы, абзацы и стили символов.
    
3. Убедиться, что текст не переполняет фреймы.
    
4. Проверить, что положение и размеры фреймов не изменились.
    
5. Сохранить документ InDesign.
    

### 7. Важные ограничения

- Не редактируйте один и тот же синхронизируемый текст одновременно в Markdown и InDesign. Источником текста считается Markdown-файл.
    
- Не изменяйте идентификаторы без соответствующего изменения заголовков в Markdown.
    
- Названия стилей должны совпадать с названиями в InDesign.
    
- Скрипт не создаёт и не удаляет содержательные текстовые фреймы.
    
- Перед первой синхронизацией и при работе с важным документом рекомендуется создать резервную копию.
    
- Текущую версию необходимо проверить на копии рабочего документа перед регулярным использованием.
