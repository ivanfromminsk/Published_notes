## Слои InDesign

Рекомендуемая структура (сверху вниз):

| Слой | Содержание |
|---|---|
| 05 — Guides | Модульная сетка, вспомогательные линии, разметка |
| 04 — Text | Заголовки, тексты, подписи, номера страниц |
| 03 — Graphics | Стрелки, линии, легенды, диаграммы, графические акценты |
| 02 — Images | Мастерпланы, схемы, карты, рендеры, фотографии |
| 01 — Background | Фоновые заливки, плашки, декоративные элементы |
| 00 — Non-print | Комментарии, инструкции и служебные элементы (не печатать) |

**Практики:**
- Разделять слои по функциям, а не по страницам или проектам; не усложнять структуру без необходимости.
- Блокировать Guides и при необходимости Background от случайного редактирования.
- Повторяющиеся элементы (логотипы, колонтитулы, нумерация) размещать на родительских страницах (Parent Pages).
- Для Non-print отключить **Print Layer** в Layer Options. Вспомогательную сетку тоже не выводить в печать.
- Использовать Paragraph Styles, Character Styles и Object Styles для единообразия оформления; слои не заменяют стили.
- Слои действуют на весь документ, а не отдельно на каждую страницу.
